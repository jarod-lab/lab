DESIGN SYSTEM · D+

Lean core. Budgeted lift.

One shell for every app we build. It works with zero downloads and no JavaScript styling, then adds a few near-free enhancements that each carry meaning.

System fonts · 0 images · 0 webfonts WCAG AAA text · keyboard-first Light + dark from the same tokens

PRINCIPLES

Lean core

System fonts, inline SVG, CSS variables. The core experience has to be complete before any enhancement loads.

Budgeted lift

Every extra must be near-free in bytes, removable without breakage, and mean something. Decoration alone doesn't qualify.

Honest by default

Yes and no get equal weight. Destructive actions say exactly what they delete. Undo where we can. Costs are visible.

Accessible as standard

7:1 text, status = shape + word, 44px targets, real elements, visible shortcuts, motion off when asked.
